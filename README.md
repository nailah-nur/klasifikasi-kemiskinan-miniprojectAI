# Klasifikasi Tingkat Kemiskinan Kabupaten/Kota di Indonesia Menggunakan Random Forest

Repositori ini berisi proyek mini Kecerdasan Buatan (AI) / Machine Learning untuk mengklasifikasikan tingkat kemiskinan kabupaten/kota di Indonesia berdasarkan berbagai indikator sosio-ekonomi.

## 📌 Deskripsi Proyek
Proyek ini melakukan pemodelan data sosio-ekonomi menggunakan Python di Google Colab. Proses mencakup:
 **Preprocessing Data:** Pemuatan dataset, pembersihan nilai kosong (*missing values*), konversi tipe data numerik, serta pemeriksaan duplikasi data.
 **Fitur / Indikator:** Rata-rata lama sekolah, pengeluaran per kapita, Indeks Pembangunan Manusia (IPM), umur harapan hidup, akses sanitasi & air minum layak, tingkat pengangguran terbuka (TPT), tingkat partisipasi angkatan kerja (TPAK), hingga PDRB.
 **Analisis & Pemodelan:** Visualisasi distribusi data target dan matriks korelasi, dilanjutkan pemodelan klasifikasi menggunakan algoritma **Random Forest** (*ensemble learning* berbasis *decision trees*).

## 📁 Struktur Repositori
* `Kelompok_1_AI_(BC)_Final.ipynb` : File Jupyter Notebook (Google Colab) yang berisi kode analisis dan pemodelan lengkap.
* `Klasifikasi Tingkat Kemiskinan di Indonesia (1).csv` : Dataset indikator sosio-ekonomi kabupaten/kota di Indonesia.

## 🚀 Cara Menjalankan Notebook
1. Unduh atau *clone* repositori ini.
2. Buka file `.ipynb` menggunakan **Google Colab** atau **Jupyter Notebook**.
3. Pastikan dataset `.csv` berada di direktori yang sama atau dimuat langsung dari tautan raw GitHub.
4. Jalankan sel kode secara berurutan.
